## B. 若开工重构：架构建议（08/09 提取，值得采纳）

1. **`src/` 源树 + 零依赖构建 → 单文件产物**（唯一同时满足「拆得开维护」与「交付物仍可双击」）。
2. **按连续行段切、保持原序**，不按语义重排——CSS 是尾部覆盖式（v7~v7.5 动效层靠顺序生效）。
3. **禁 ES module / 禁打包器 / 零 `node_modules`**（本机实测：`file://` 下 `<script type="module">` 被 CORS 拦截，传统 script + 外链 CSS 可用）。
4. **开发态 `src/index.html` 双击直接跑**，构建只在出交付版时需要。
5. 产物形态不变：单文件、**CRLF**、末尾无换行、不压缩（交付物即源码的调试价值优先）。
6. `_build/` 四分区归位（`verify/` `diag/` `snapshots/` `artifacts/`），用快照替代 30 份 150KB 整文件拷贝（约 4.5MB 冗余）。
7. 施工纪律：只搬不改（不改命名/缩进/写法）、`'use strict'` 只在第 1 片、`load()` 留在最后一片末尾、每阶段先过闸门再提交。
8. 切分粒度：16 片 JS（`68-drag.js` 297 行、`40-template.js` 322 行可按同序再细分）；7 片 CSS 含「叠层高亮铁律」（`.blk-hl` 与 `.blk-input` 排版声明逐字一致）。
9. **注意 08 与 09 冲突**：08（旧稿）说 11 片 + IIFE 挂 `PHJ` 命名空间 + 抽骨架；09 定 16 片 + 禁 IIFE + 骨架原地保留。**以 09 为准**，照 08 做会踩红线。
