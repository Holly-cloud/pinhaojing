# 拼好镜

把一条视频提示词拆成**可自由摆放的提示词块**，在无限画布上排布、拼接、导出——
一个「**双击即开、用完即走**」的写作小工具。

> 当前版本 **v7.20** ｜ 产物 `PHJ.html` = 324783 B ｜ 验收：`node dev/_qa/run-gate.mjs` → **15/15 全绿**

## 怎么用（三步）

1. **双击 `PHJ.html`** —— 直接打开。零安装、零网络、零后台进程、不动你的系统。
2. **默认进「写作台」**：左边大纲、右边大编辑器，逐条写分镜、边写边存。
   顶栏「写作 / 画布」胶囊可随时切到**画布**排版。
3. **数据自动保存在浏览器本地**；要换机或备份时，用面板的「导出 JSON」／「导出写作资产」带走。

## 主要功能

| 场景 | 能力 |
|---|---|
| **写作台**（默认） | 左栏大纲 + 右栏大编辑器；逐条写、实时写回；拖 ⠿ 调整顺序（不影响画布位置） |
| **画布** | 无限画布、无滚动条；双击空白新增块；拖空白平移、滚轮滑动；块宽高随文本自适应；一键整理；拖动手柄永远置顶 |
| **拼接栏** | 按序把块拼成整条 prompt；模板预设；一键复制全文 |
| **写作补全** | 输入 `#` 唤起候选气泡（结构层 / 槽位 / 两级分组）；「未用过」徽章随写作动态消失；查询按使用习惯加权；配置窗内置「语料体检」 |
| **灵感气泡群** | 编辑区右下角常驻漂浮，**跟随你当前写到哪一节实时换内容**；点一下直接补进正文；可折叠、可「换一批」 |
| **多项目** | 当前项目名常显于顶栏与写作台左栏，点击即新建 / 切换；各项目独立一套块、视角与拼接栏，切走再切回**原样在场** |
| **编排工具** | 放大编辑弹窗（内含一键「逗号转空格（台词除外）」）；移除空行；复制全文 |
| **数据安全** | 自动保存 + 导出 / 导入 JSON；危险操作（删项目）有确认与撤销 |
