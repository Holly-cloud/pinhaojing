## 一句话定位

> **拼好镜**：一个「双击即开、用完即走」的**单文件 HTML** 写作小工具。默认落在**写作台**视图（顶栏「写作 / 画布」胶囊切换）——**左大纲 + 右大编辑器**，逐条写分镜、实时写回；切到**画布**视图则把同一条视频提示词拆成**无限画布上自由摆放的提示词块**：画布无边无滚动条，**双击空白新增块**、拖空白平移视角、滚轮上下滑动；块**宽高随文本自适应**；**一键整理**；块可任意重叠，**拖动手柄永远置顶可操作**；右侧**拼接栏**按序拼成整条 prompt，支持**模板预设**与**写作补全**（结构层 / 候选气泡 / 槽位——「未用过」徽章随你实际写作**动态消失**、查询结果按**使用习惯**加权、配置窗内置「**语料体检**」）；**放大编辑**弹窗内可一键「**逗号转空格**（台词除外）」；顶栏「**项目**」可**新建 / 切换多个独立项目**（各自一套块、视角与拼接栏，切走再切回原样在场）；**编辑器内 Ctrl+V 不再被画布抢占**；重开工具后画布块高不再塌陷（间距稳定）。数据自动保存 + 导出/导入 JSON。**零安装、零进程、零系统残留。**

## 六、架构现状（R0–R4 收口后 · 截至 v7.18）

- **源码 = 19 个引擎模块 + 1 片皮肤**（`dev/src/{shell,core,editor,view,interact}/` = **引擎（零领域语义）**；`dev/src/skin/` = **域内容**）；顺序由 `dev/manifest.mjs` 的 `SLICES`（**20 条 = 加载序**）**唯一给出**，`build.mjs` 只读 manifest、**不再扫 `index.html`**。末片 = `shell/wiring.js`（**R2 由 `shell/boot.js` 改名，只改名不拆**）。
- **编辑器宿主化（v7.15）**：编辑器内核（`editor/highlight.js` / `editor/complete.js`）按**宿主对象**寻址（`editor/host.js` 的 `makeHost`）——`hostPopup`（`#blkMask` 弹窗）/ `hostDesk`（`#writeDesk` 写作台右栏）**复用同一内核**；写作台视图 = `view/write.js` + `styles/55-write.css`（左大纲 + 右大编辑器，与画布**同源**同一份 `state.blocks`）。
- **引擎 × 皮肤分层（R1）**：方向单一 —— 引擎**不得**引用 `skin/`，`skin/` **不得**反向依赖引擎；由 `verify_v78.mjs` 的 **R1 皮肤边界** + **R1 语料归属** 两条断言守门。含义：**换领域只需替换 `skin/`，不动引擎**。当前 `skin/` 仅 1 片 `corpus.js`。
- **边界机制化（R3/R4，2026-09-17 新增）**：「引擎零领域语义」不再只是一句注释 —— **R3-A 棘轮**（皮肤词元命中引擎代码的去重数 ≤ 冻结尾数 **15**，只堵新增）+ **R3-B 零泄漏**（皮肤长语料 **∪ 全部 `【…】` 完整标记串** 在非皮肤原文零命中）+ **R3-C 守卫自检**（皮肤采集非空 + 数量下限，防 `skin/` 清空后 R3-A/R3-B **真空通过**）+ **R4 皮肤可摘除**（真读产物：摘除皮肤后逐字节 == 非皮肤片拼接）。口径见 `dev/_qa/lib/skin-guard.mjs`。
- **产物 = 单个 IIFE + 严格模式**；**开发态与产物跑同一份字节**（`dev/src/dev-bundle.js` = 产物内联 JS 段逐字）。
- **Escape 单点分发**：唯一 document 级 Esc = `interact/keys.js` 的 `closeTopLayer()`；会话态唯一来源 = `core/store.js`；`PHJ.<module>` = 显式对外面（共 **135** 名），**不是调用通道**。
- **闸门**：`node dev/_qa/run-gate.mjs` 一条命令跑 13 道（**83 / 18 / 16 / 54 / 18 / 21 / 31 / 16 / 4 / 9 / 4**）；快照角色与维护约定见 `dev/_qa/snapshots/INDEX.md`。
