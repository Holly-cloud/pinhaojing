## 一句话定位（v6.0）

> **拼好镜**：一个「双击即开、用完即走」的单文件 HTML 小工具。把一条视频提示词拆成**无限画布上自由摆放的提示词块**：画布无边、无滚动条，**双击空白新增块**、拖空白平移视角、**滚轮上下滑动**；块**宽高均随文本自适应**（一整行完整显示、不自动换行）；**一键整理**（自上而下左对齐）；块可任意重叠，**拖动手柄永远置顶可操作**；右侧**拼接栏**按序拼成整条 prompt，支持**模板预设**（存为模板/套用=替换/改名/删除）；数据自动保存 + 导出/导入 JSON。零安装、零进程、零系统残留。
