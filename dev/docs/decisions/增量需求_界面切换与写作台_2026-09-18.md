### 0.1 本次要解决的核心矛盾

现状产品的心智是「**画布 = 主体**」：双击即见无限画布，顶栏四键（整/导/补/100%）、右侧拼接栏、块的操作语义（拖手/摆放/重叠/连线）全部围绕**空间化整理**。但 Holly 的高频动作其实是「**一条一条把分镜提示词写出来**」——写作时，画布的空间感（无限延伸、块重叠、遮挡、坐标、拼接栏）是**负担**而非助力。

本次即：**把"写作"从画布里独立出来成为主界面，把画布降格为"另一个视图"**。

### 0.2 一句话方案

> 顶栏加一个**胶囊分段控件「写作 / 画布」**；**启动默认进「写作台」**（左大纲 + 右大编辑器双栏）；**「画布」保留原样**，一键可达。两个界面是**同一批块的两种视图、实时同步**。

### 0.3 本次改动边界（做 / 不做）

- **做**：视图切换控件；写作台（左大纲 + 右大编辑器）；顺序字段带来的"写作顺序"能力；两视图同源同步；写作台内的快捷键与画布专属交互的隔离。
- **不做**：画布/拼接栏/模板/补全等既有能力的重做或删除；任何数据结构的字段级设计（架构师）；图片块的写作台形态（先明确不入大纲，见 §6-Q3）；多级大纲/分组（P2）。

## 1. 产品目标 + 「专注」的语义定义 ★

### 1.1 产品目标（3 个，正交）

1. **让"写"成为默认动作**：打开工具的第一眼是"待写的分镜列表 + 正在写的那一条"，而不是一张需要被管理的画布。
2. **降格画布、不削弱画布**：画布从"主体"变为"视图之一"，一键可达、能力不减、数据不丢。
3. **顺序与位置解耦**：让"分镜的先后（叙事顺序）"成为一等公民，不再只能靠"块的 y 坐标"间接表达。

### 1.2 「专注写分镜提示词」的语义定义 ★

> **专注 = 一次只想一条，其余退场。**
> 屏幕上只存在「**当前这一条分镜的正文**」+「**它在序列中的位置**」两件事；一切属于"管理 / 组装 / 空间摆放"的信息全部退出视野。

#### 1.2.1 写作台要**屏蔽掉**什么（退场清单）

| 退场对象 | 为什么它是干扰 |
|---|---|
| **无限画布的空间感**：平移 / 缩放 / 视角 / 无限延伸 | 写作是线性的，空间感制造"还有看不到的地方"的焦虑。 |
| **块的空间属性**：坐标、自由摆放、重叠、遮挡、层级置顶、拖手光点、拼接光线 | 这些属于"摆放"，写作时与内容无关。 |
| **拼接栏 / 模板 / 拼模式** | 属于"组装态"（把块拼成整条 prompt），是**画布视图的工作**。 |
| **非当前分镜的正文** | 左栏只留**摘要**，正文一次只出现一条。 |
| **画布专属操作**：双击空白新增、右键画布菜单、Ctrl+左键多选、方向键平移、空格平移、Ctrl+滚轮缩放 | 它们在写作台里会误触、会与文本编辑抢键。 |
| **图片块**（`type:'image'`） | 仅展示用、无文本；混进"写作列表"会打断线性节奏（先不入大纲，见 §6-Q3）。 |
| **弹窗式编辑的"确定 / 取消"** | 弹窗制造"未提交"状态与中断感；写作台要求**输入即所见即所存**。 |
| **高频弹窗 / 向导 / 二次确认** | 一切打断写作流的东西退场（删除走"乐观删除 + 撤销"）。 |

#### 1.2.2 写作台要**强化**什么（到场清单）

| 强化对象 | 具体形态 |
|---|---|
| **① 正文即主体** | 右栏大号编辑器**填满整栏**（去掉现有编辑窗"80vh / 560px"的弹窗尺寸约束），当前条目的文字是画面上最大的信息。 |
| **② 顺序感** | 左栏序号 + 当前项高亮 + 上/下邻居的摘要可见；状态区永远知道「**第 3 条 / 共 12 条**」。 |
| **③ 写作基础设施常驻** | 复用现有 coding 编辑器能力并**常驻可见**：行号栏 / 叠层语法高亮 / 结构层「**节**」显示 / `#` 触发的结构感知候选补全 / 槽位 `${n}` / 状态栏（行·列·字符·错误符号）/ 「移除空行」。它们不再是"点开才有的弹窗功能"，而是写作台的**底座**。 |
| **④ 不打断** | 无"确定/取消"、无"保存"按钮；输入即写入同一块文本，防抖落盘。切换视图 / 关窗 / 关页都不丢字。 |
| **⑤ 一条接一条的节奏** | 最小动作链：**新建 → 写 → 下一条**，全程不离开键盘（`Alt+Enter` 新建并直接开写、`Alt+↑/↓` 上下条切换）。 |
| **⑥ 一键退出现有秩序**（可选强化） | 左栏折叠（P1）/ 专注态可退，随时切回画布，**专注不 = 被困住**。 |

#### 1.2.3 「专注」的**反面（明确不是）**

- 专注 **≠** 全屏无 UI：顶栏的**视图切换**、条目计数、必要状态必须保留（否则用户会"迷路"）。
- 专注 **≠** 禁止看画布：一键可切，且切回**不丢任何东西**。
- 专注 **≠** 隐藏一切结构信息：行号 / 节 / 补全恰恰是"写作时的脚手架"，**必须留**。

## 2. 用户故事（6 条）

- **US1（默认入口）**：作为**每天来写分镜的创作者**，我希望**打开工具就直接是"写作台"**，以便不必先面对满屏画布再去找入口。
- **US2（一条一条写）**：作为**写分镜的人**，我希望**左栏列出全部分镜、右栏放大写当前这一条**，以便一次只盯一条、不被别的块和空间摆放干扰。
- **US3（调顺序）**：作为**在调叙事顺序的人**，我希望**在大纲里拖动就能改分镜先后**，以便调整顺序时不用回到画布重新摆块位置。
- **US4（不打断）**：作为**连续写作的人**，我希望**新增 / 删除 / 上下移都有顺手入口（按钮 + 快捷键 + 右键）**，以便写作流不被鼠标往返打断。
- **US5（老用户不丢东西）**：作为**已经在画布上摆过块的老用户**，我希望**写作台和画布是同一批内容、随时切换都不丢**，以便在"写"与"摆"之间自由切换。
- **US6（画布仍是能力）**：作为**需要空间化整理 / 拼装整条 prompt 的人**，我希望**画布作为一个视图原样保留、一键可达**，以便需要那套能力时它还在。

### 4.3 视图切换瞬间的行为

| 时机 | 行为（应明确、可预期） |
|---|---|
| **启动** | 默认进**写作台**（P0-2）；选中项 = 第一条文本块；焦点落**右栏编辑器文末**（可直接开写）。 |
| **画布 → 写作台** | ① 画布的 `pan`/`zoom` **原样保留**（不归零），切回时视角如旧；② 若画布上"最近操作/编辑过"的块存在 → 写作台**选中该条**并滚动到可见；否则选第一条；③ 编辑器聚焦并光标落文末；④ 若有正在进行的输入（画布块 textarea）→ **先落盘**再切。 |

### 4.4 键盘快捷键方案（新增，且**不冲突**）

**已占用键（现状，必须尊重）**：`←→↑↓`（平滑移动画布，输入态与弹窗内豁免）｜`Space`（按住平移画布）｜`Esc`（统一关闭最上层）｜`Ctrl+V`（粘贴为块；输入态豁免）｜`Ctrl+Shift+C`（编辑器内复制全文）｜候选气泡内 `1–9` / `↑↓` / `Enter`·`Tab` / `Esc`；配置窗内 `Ctrl/⌘+Enter`；`Ctrl+左键`（多选）、`Ctrl+滚轮`（缩放）、双击空白（新增块）。

**写作台新增（用 `Alt` 家族，与上面零交叠；仅**写作视图**内生效）**：

| 快捷键 | 动作 | 说明 |
|---|---|---|
| `Alt+↑` / `Alt+↓` | 上一条 / 下一条分镜 | **切换选中条目**；切换前自动落盘当前编辑；右栏编辑器随之切换内容。 |
| `Alt+Shift+↑` / `Alt+Shift+↓` | 当前分镜上移 / 下移一位 | 与上一组同族：**加 `Shift` = 改顺序**；带「已调整顺序（不影响画布位置）」toast。 |
| `Alt+Enter` | 在当前分镜**之后新建一条**并聚焦编辑器 | 最小动作链的核心（新建即开写）。 |
| `Alt+Backspace` | 删除当前分镜（乐观删除 + 「撤销」toast） | 若某环境被输入法/系统占用，**降级为右键菜单/`×`**（删除入口不止此一路）；见 §6-Q10。 |
| （P1）`Alt+Home` / `Alt+End` | 跳首 / 末条 | 长列表快速定位。 |
| （P1）`Alt+1` / `Alt+2` | 切到写作台 / 画布 | 占用风险见 §6-Q10。 |

**焦点分区规则（避免抢键）**：

- 焦点在**右栏编辑器**时 → 上述 `Alt+*` 仍生效；**但**文本输入相关键（字母/数字/`Enter`/`Tab`/`←→`/`Backspace`）**全部归编辑器**（原生行为，候选气泡在 `#` 触发时按现状接管 `1–9`·`↑↓`·`Enter`·`Esc`）。
- 焦点在**左栏大纲**时 → `↑`/`↓` = **列表导航**（切换选中条目）；`Enter` = 聚焦右栏编辑器进入编辑；`Space` **无动作**（不平移）。
- **`Esc` 语义不变**：始终 = 关闭最上层（**不用于切换视图**，避免误切）。

### 4.5 在写作台里**应被禁用**的快捷键 / 交互

| 对象 | 处置 | 理由 |
|---|---|---|
| `←→↑↓` 画布平移 | **禁用**（写作视图内一律不动画布） | 左栏用 `↑↓` 导航、右栏用方向键移光标；平移画布在此无意义且会"跑视角"。 |
| `Space` 按住平移 | **禁用** | 写作台内空格是输入/无动作，绝不能触发平移。 |
| `Ctrl+滚轮` 画布缩放 | **禁用**（滚轮 = 当前栏滚动） | 画布不可见，缩放无对象。 |
| 双击空白新增块 | **不适用**（无画布） | 避免"双击到空白就冒出块"。 |
| 画布右键菜单 | **禁用**（改为条目右键菜单，P1-7） | 语义替换。 |
| `Ctrl+左键` 多选 | **禁用**（左栏点击 = 单选） | 写作台不需要多选语义（多选移动为 P2-2）。 |
| `Esc` 关闭最上层 | **保留** | 与全局一致。 |
| `Ctrl+V` | **保留**：编辑器内为原生粘贴；左栏区为"粘贴为新分镜"（P1-5） | 避免"换界面就不能粘贴"的落差。 |
| `Ctrl+Shift+C` | **保留**：编辑器内复制全文 | 与现状一致。 |

### 4.6 空状态

| 场景 | 表现 |
|---|---|
| **一条都没有** | 左栏：居中引导「**还没有分镜** · 点『＋ 新建分镜』或按 `Alt+Enter` 写下第一条」；右栏：编辑器置为**不可编辑占位**（灰字提示"新建后在此写作"），避免"能打字却不知道存到哪"。 |
| **过滤后无结果**（P1-2） | 左栏：「没有匹配的分镜」+ 清空过滤提示；**不自动改顺序**。 |
| **最后一条被删除** | 回到上面的"一条都没有"空态；给一次「撤销」机会。 |

## 5. 边界与异常

### 5.1 块非常多（50+）

- **左栏形态**：条目为**固定高单行**，左栏**独立滚动**；不因条目多而压缩或换行。
- **性能期望**：**100 条**时左栏滚动、拖拽排序、单条切换均**无肉眼卡顿**（不要求虚拟滚动，但需实测达标）。
- **当前项可见性**：切换选中项 / `Alt+↑↓` 后，当前项 `scrollIntoView` 保持可见（不跳顶、不跳底）。
- **可发现性**：条目多时，"新增"按钮固定在**左栏底部**（不随滚动消失）；P1-2 提供搜索过滤。
- **例外**：不因条目多而改变"序号 1..N 连续"的口径。

### 5.2 超长文本

- **大纲侧**：摘要**强制单行截断**（含 `…`）；字数**完整显示**（不截断数字），让用户知道"这条很长"。
- **编辑器侧**：不做截断；沿用现有 textarea + 叠层方案；极长单条（如 >10k 字符）编辑不崩、状态栏字数准确。
- **行号 / 高亮**：与现有块编辑器**同口径**（同一内核、同一行为），不因大尺寸出现新的错位。

### 5.3 图片块（`type:'image'`）

- **默认口径**：图片块**不进入写作台大纲**（无文本、仅会话内、不可拼接）。
- **兜底**：若被选中的项是图片块 → **自动落到第一条文本块**，不出现"选中了却无字可编辑"的空屏。
- **可发现性**：写作台可给一行**灰字提示**「画布另有 M 张图片（仅画布可见）」（P1 可选）。
- **计数口径**：「分镜 N 条」**不含**图片块；避免用户以为"少了一条"。
- 是否要让图片作为"参考图"进入写作台 → **§6-Q3 待定**。

### 5.4 「顺序」与「位置」不一致时的**解释口径** ★

**风险**：用户在写作台看到序号 1..N，回到画布发现块的位置"完全不是这个顺序"（因为 `x/y` 没变），会疑惑"到底以哪个为准？是不是坏了？"。

**化解（文案 + 默认行为 + 可选收敛，三管齐下）**：

1. **一句话口径（写进左栏栏头）**：
   > **大纲管顺序，画布管位置——顺序决定"先讲哪条"，位置只决定"摆在哪儿"，两者互不影响。**
2. **动作即时反馈**：拖动排序后 toast「**已调整顺序（不影响画布位置）**」——在用户刚产生疑惑的那一刻解释。
3. **默认让两者"看起来一致"**：老数据迁移时 `order` 缺省按**原画布自上而下顺序**（P0-14），使新用户/老用户**初体验不会冲突**；只有用户**主动**在画布重排后又不管顺序，才会分叉——此时以**左栏序号**为唯一"顺序真相"。
4. **可选收敛手段（P1-3 / P1-4）**：画布块显示 `order` **角标**；「整」增加「按大纲顺序整理」——让需要时能把两者**对齐**，但**默认不强制**。

### 5.5 切换界面时"正在编辑未提交的内容"怎么办

- **产品口径：不存在"未提交"状态。** 写作台编辑器为**实时写回**（P0-9），与画布内联编辑一致——**没有"确定 / 取消"、没有"保存"按钮**，输入即写入同一块文本（防抖落盘）。
- 因此：切换视图 / 关闭最上层 / 关闭页面，**都不会丢字**；切换前额外做一次 **flush**（清防抖定时器立即落盘）。
- 若架构师判定右栏必须先走"弹窗式编辑器"（有未提交态）→ **与本条冲突，需回退到 §6-Q7 澄清**（当前倾向：**拒绝弹窗式**，保持实时写回）。

### 5.6 其它异常

| 场景 | 处置 |
|---|---|
| 升级自 v14 及更早（无 `order`） | `migrate` v1→v15 补 `order`（= 原 `y` 后 `x` 顺序）；**逐条零丢失**（P0-14）。 |
| 导入旧版 JSON | 同上一行口径（导入即迁移）。 |
| 切到画布又切回 | 选中项与左栏滚动位置**会话内保留**；（重开浏览器后是否保留 → §6-Q1）。 |
| 同一条在极短时间被连续编辑 | 防抖合并落盘；不产生重复条目。 |
| 候选气泡 / 状态栏在切换瞬间 | 切换即**重置**编辑器的补全/槽位临时态（与现有关窗口径一致），不留残留气泡。 |
| `prefers-reduced-motion` | 视图切换、新建、删除、提示动效**降级为无动画**（P0-15）。 |
| 极端：写作台右栏在窄窗口 | 双栏在窄窗口下的下限行为（是否自动折为单栏/最小宽度）→ **§6-Q6**。 |
