## 5. 本次审计修掉的缺陷：版本快照的行尾

**症状（修复前实测）**：换机（`autocrlf=false`）后 → 快照落为 **LF**（230233 B），而 `build.mjs` 固定输出 **CRLF**（234243 B）→ **等价性闸门 FAIL**。

**根因**：版本快照的 **git blob 是 LF**（历史提交时被 `core.autocrlf=true` 剥掉了 CR）。本机 `core.autocrlf=true` 会在 checkout 时补回 CRLF，所以本机一直没暴露；换到 `autocrlf=false`（macOS/Linux 默认）就按 blob 原样检出。

**修复**（提交 `33a1419` + `34a783d`）：
- 新增 **`.gitattributes`**：`* text=auto`（保持既有行为）+ **`PHJ.html -text`**、**`dev/_qa/snapshots/**/*.html -text`**（`-text` = 永不转换 → 任何机器检出即仓库字节 CRLF）〔2026-09-17 结构整理：`dev/_build/` 已更名 `dev/_qa/`，规则路径随之更新〕
- `git add --renormalize` 把交付物与全部快照**按 CRLF 原字节重新入库**
- ⚠️ 写 `.gitattributes` 时注意**行序**：git 取**最后一条匹配**，具体规则必须写在 `* text=auto` **之后**（否则会被覆盖——本次第一版就踩了这个坑）

## 6. 已知限制与兜底

| 项 | 现状 | 兜底/说明 |
|---|---|---|
| 浏览器自动探测 | Windows 候选优先；已于本次补齐 **macOS / Linux 候选**（`/Applications/*.app/…`、`/usr/bin/{microsoft-edge,google-chrome,chromium}*`、`/snap/bin/chromium`） | 仍探测不到 → **`PHJ_BROWSER=<可执行文件绝对路径>` 硬覆盖**（不可用则明确报错，**不静默回落**） |
| 源码/脚本行尾 | 随各机 `core.autocrlf`（本机 CRLF、干净克隆可能 LF） | **无影响**：`build.mjs` 对输入做 CRLF→LF 归一化，产物行尾由其固定为 CRLF |
| 本机专属配置 | `core.autocrlf=true`、Edge 路径、`%TEMP%` 约定 | 都不入仓库；换机不必复制任何本地配置 |
| 数据（用户内容） | 存在浏览器 `localStorage`（`file://` 域，键 `storyboard-prompt-panel:v1`） | **不随文件走**。迁移用面板自带「导出 JSON」（以及「导出写作资产」），在新机导入即可 |
| 体积门槛 | 已解除（2026-09-16）：无产品上限、无工程护栏 | 体积仍打印，仅报告 |
