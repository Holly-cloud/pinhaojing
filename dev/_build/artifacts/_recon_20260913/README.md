## 二、结论：指导书**行段可用**，但**参考实现有两处会误伤施工方**

自检输出（本机 Node v22.23.2）：

```
行段对账      CSS 7 片 = 316 行 ✓ 无损回拼 ✓ ｜ JS 16 片 = 2285 行 ✓ 无损回拼 ✓
构建 A（第 8 节参考实现逐字）        155309 B   严格等价 = false
构建 B（A 上一处字符修正）           155315 B   严格等价 = true   ← 与指导书声称的字节数一致
```

1. **第 8 节 `build.mjs`：内联吞掉「片尾空行」。**
   `all += body.replace(/\n+$/, '') + '\n'` 把每一片的**全部**尾随换行剥掉，而 16 片 JS 里有 3 片恰好以空行结尾（第 585、630、1861 行是空行，属 10-state / 15-clipboard / 60-keyboard 三片的末行）。
   后果：产物 155309 B（≠ 155315 B），等价性闸门 **FAIL**，且第 9 节校验脚本会打印「**script 段：★ 不一致 → 回第 6 节重切行段**」——而第 6 节行段是对的。照指导书第 10 节「失败处理：回退该片，核对行段边界后重切」执行，会陷入**无限重切**。
   修正：`/\n+$/` → `/\n$/`（只剥文件自身那一个换行符）。

2. **第 9 节 `verify_build_equivalence.mjs`：`stripBanner` 锚不上第 2 行的 banner。**
   `s.replace(/^<!--\s*构建生成[\s\S]*?-->\r?\n/, '')` 少了 `m` 标志；而第 8 节明确把 banner 插在 `<!DOCTYPE html>` **之后**（第 2 行）。
   后果：**即使产物逐字节完美，也报 ❌ FAIL**（首次差异报在第 2 行 banner），并落到「仅格式差异」分支的误导性提示上。
   修正：正则补 `m` 标志。
   （第 8 节末尾「若首行不是 `<!DOCTYPE html>`，banner 改为插到文件最前」这条兜底**不生效**——本文件首行正是 `<!DOCTYPE html>`。）

两处各改一个字符后：产物 **155315 B**、剥离 banner 后**逐字节严格相等**、`style 段` 与 `script 段` 均一致。
