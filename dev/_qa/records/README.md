## 二、明确约定

1. **本目录内的 `archive/` 脚本含整理前旧路径**（如 `dev/_build/…`、`_recon_20260913/…`），属**历史留档**——**不修、不跑**；当前位置以 `dev/docs/README.md` 的映射表为准。
2. 本目录**只增不改**：新增留档请附一句「它为哪份文档/哪个版本作证」。
3. 删除留档**必须**同步处理引用它的文档（否则文档里的图/数据会指向不存在的文件）。
