### 第三轮（v7.21c）· 「节」判定修正 + 灵感气泡按行内内容排组 ★

> Holly 报告：**「文本编辑器对当前所处"节"的判断始终错误　请让它仅根据当前整行文字的特征判断所处内容段」**；澄清后确认抱怨点 = **状态栏节名随位置漂移**（块内「镜头1 …」恒判「起手式」，因其前无「画面开始：」），且希望气泡**按行内内容**给灵感。
> 根因：`structMap` 是**状态机**（从全文首行累积 region），`structAt` 直接取其值 ⇒ 判定**位置相关**。

| 项 | 内容 |
|---|---|
| **★label / region 职责分离** | `structAt` 的 `label` = 「光标这一行像什么」→ **纯行首特征·行级**；`region` = 「这一段处于哪个区」→ **段落延续**（原 `structMap` 语义，**逐字未动**）。同一行二者**不必一致**（注释已写明）。⇒ **逗号豁免零影响**（QA 独立核对：`structMap` 函数体 31 行逐字未变，`verify_c` 文件未改动、A1/A6/A7/A8 全绿） |
| **label 行级映射** | `^镜头N` → 「分镜 镜头N」（★一律分镜，Holly 裁决）；`^画面开始/结束` / `^风格[:：]` / `^硬性要求[:：]` / `^【属性】` 各归其位；**未命中（含空行）→「判断中」**（Holly 口径：判不出就悬空，不敲定）。旧 label「起手式」「叙事正文」不再出现 |
| **★灵感气泡按行内内容排组** | `#wdBubbles` 候选组 = **本节相关组 ∪ 行内命中组**（命中数降序 → 本节相关优先 → 原组序；无命中 ⇒ 与旧行为逐字一致）。**引擎零领域词表**：拿行内词匹配 `cmplActive()` 既有条目 |
| **★切词前剥离行首「镜头N」序号（方案 D）** | `镜头1` 是序号、无内容语义，却是「起手式」组样板（`镜头1·@首帧画面·…`）的子串 ⇒ **任何镜头行都误命中**（第一版并集实现因此把 v7.20 C4 打红：渲染池 36 ≠ 参照池 32）。**只剥 shot 类型**；`【属性】`/`风格：`/`硬性要求：` 有语义、不剥 |
