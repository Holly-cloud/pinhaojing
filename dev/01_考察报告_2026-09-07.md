## 3. 技术选型（已拍板）

### 3.1 形态：单文件 HTML ✅
- 双击 `分镜提示词面板.html`，浏览器 file:// 直开；无安装、无进程常驻、无环境变量、无端口。
- 数据：localStorage 防抖自动保存 + 导出/导入 JSON 完成便携（硬备份兜底 file:// 下 localStorage 被清理的极小概率）。
- 对比过的备选「便携文件夹 + Python 本地服务」（数据落真 JSON 文件）→ 依赖 Python + 起端口，不符合「零污染」纯度，弃用。

### 3.2 拖拽引擎：SortableJS（内嵌单文件化）✅
- 2026 对比结论 [1]：框架无关、纯 DOM、MIT；**跨 React/Vue/纯 HTML 页面的通用选择**；31k+ stars；touch 原生支持。
- 与单文件 HTML 完全契合：约 44KB min，直接内联，**固定版本、离线可用、无 CDN 依赖**。
- 备选：dnd-kit（React 向）/ react-dnd（旧 React）——本项目用 vanilla，不选；手写 HTML5 DnD——有 dragenter/dragleave 抖动坑 [1]，不选。

### 3.3 快捷复制 ✅
- `navigator.clipboard.writeText`（file:// 属安全上下文）+ `execCommand('copy')` 隐藏 textarea 兜底（Firefox）。
- 三种粒度：单块复制 / 块克隆（副本）/ 整条分镜按序拼接复制。

## 4. 块设计（已拍板：极简通用文本块）

**拍板原文：「极简，纯粹的可拖拽通用文本块」。**

- **不做**字段化镜头表单（时间/运镜/画面/光线分字段）、**不做**模型预设模板（Seedance/H3/Ref2VA）。
- 每一块 = （可选标题行 + 一段提示词文本）的通用文本块；N 块竖排，拖拽即排序，**顺序即分镜顺序**。
- 块文本自由：一段镜头描述、一句风格统一句、一条声音规范、参考素材注明……语义由用户自定，面板不预设。
- 快捷复制：单块复制（剪贴板）+ 块克隆（生成副本）+ 顶栏「复制全部」（按序拼接，v1 不拼标题、不自动编号，保持成品纯文本纯净）。

## 5. 验收标准草案（对齐「零污染便携」铁律，详见工程计划 §3.3）

- G：拿到 HTML 文件 → W：双击浏览器打开 → T：面板即用，无安装/编译/服务进程。
- G：拖动块 → T：顺序变化平滑，刷新后保持。
- G：块上复制/克隆 → T：剪贴板进文本 / 副本插其后；顶栏复制全部 → 按序拼接进剪贴板。
- G：编辑块 → T：自动保存，重开不丢。
- G：导出 → T：得 JSON；换机导入 → 完整还原。
- G：全程 → T：无 pip install、无 venv、无注册表/自启/系统目录写入，浏览器关掉即零残留。
