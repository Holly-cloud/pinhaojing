## 2. 功能清单（v3(final) 定格）

- **无限画布**：无滚动条、坐标不限（可负）、拖空白平移视角、pan 持久化
- **把手置顶**：拖动手柄 `z-index:9999`，重叠时始终可见可操作；hover 整块置顶
- **块编辑**：原生 textarea，回车 / Backspace 全浏览器原生，空行原样保留，高度随内容自动长高全文展开
- **块操作**：单块复制（trim 进剪贴板）/ 克隆（错位 +28,+28）/ 删除
- **持久化**：localStorage 防抖自动保存（400ms）+ beforeunload/visibilitychange 兜底
- **便携**：导出 / 导入 JSON（导入前自动备份、toast 可撤销）；v1/v2 旧数据自动迁移
- **零污染**：双击即用；无安装、无进程、无注册表写入、无网络（全离线）
- **明确不做**（已拍板移除）：复制全部、序号徽章、字段化表单、模型预设、画布缩放、主题皮肤

## 4. 使用说明（极简主路径）

1. **双击** `storyboard-prompt-panel.html` → 浏览器打开即用
2. 顶栏：`分镜标题`（可改名）｜ `＋ 新增块`（落在当前视口中心）｜ `⭳ 导出`（JSON 硬备份）｜ `⤒ 导入`
3. 画布：**拖块把手**摆放；**拖空白**平移视角；点空白取消输入焦点
4. 块右上角 hover 浮现操作：**复制**（单块进剪贴板）/ **克隆**（生成副本）/ **删除**
5. 数据自动保存于本机浏览器（localStorage），**重要分镜定期「导出」做硬备份**

## 5. 已知边界

- 数据存于 file:// 域 localStorage，浏览器清理策略可能清除 → 用「导出」硬备份（左下 hint 有提示）
- Firefox file:// 下剪贴板受限 → 自动走 execCommand 兜底
- 重叠块仅**把手**保证置顶可操作；被上层块体盖住的操作按钮需先 hover 或移开上层块
- 无多项目切换 / 无画布缩放 / 无主题皮肤（已拍板不做）
