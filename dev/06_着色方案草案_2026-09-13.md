### 4.3 coding 化（按你的勾选：三项 + 配对）

| # | 装备 | 实现要点 |
|---|---|---|
| ① | **等宽字体** | 两层同用 `ui-monospace, "Cascadia Mono", Consolas, "SF Mono", Menlo, "Microsoft YaHei", monospace`（中文自动回退系统字），字号行高不变 |
| ② | **行号栏** | 彩色层按逻辑行输出 `<div class="hl-line"><span class="ln">N</span>…</div>`；`.ln` 绝对定位落在左侧留白（`padding-left:52px`，行号右缘距文本左缘约 12px）→ **不占文本流、软换行续行不编号、随内容滚动**；错误行行号标红加粗 |
| ③ | **状态栏** | 窗口底部信息带：`行 N，列 M` · `字符 K` · `E 处错误符号` · `UTF-8 · LF`；光标事件驱动 |
| ④ | **括号配对高亮** | 光标紧邻的括号 → 与其配对括号加淡蓝底（`rgba(0,113,227,.16)`）；栈式向后/向前扫描，**不跨行**；错误符号不参与 |
| ✗ | 缩进参考线 / Tab 缩进 | **按你的勾选不做**（实施时不做，草案留档） |

### 4.4 零领域语义（设计红线，源自你的第三轮反馈）

引擎**只认符号的结构**（成对 / 非成对 / 属错误集），**不为任何符号预设"它代表什么内容"**：色板的分类列只写「花括号 / 圆括号 / 引号族…」这类结构名，不写「台词 / 音效 / 音乐 / 字幕」。色相分配只是"让相邻族可分"，更换色相不影响引擎语义。

## 六、技术方案：叠层高亮（overlay）

```html
<div class="blk-edit">
  <pre class="blk-hl" aria-hidden="true"><code id="blkHl"></code></pre>  <!-- 彩色层（含行号）：只显示 -->
  <textarea class="blk-input" id="blkInput"></textarea>                  <!-- 编辑层：文字透明、光标可见 -->
  <div class="blk-status">行/列 · 字符 · 错误数 · UTF-8 · LF</div>        <!-- 状态栏 -->
</div>
```

**CSS 关键**（两层逐字一致，否则错位）：字体度量（等宽 + 13.5px + 1.65 + `letter-spacing:0` + `tab-size:4`）、盒模型（`padding:10px 12px 10px 52px` + 1px 透明边框）、换行算法（`pre-wrap` + `break-word`）；分层：textarea 在上（`background:transparent` / `-webkit-text-fill-color:transparent` / `caret-color` / `::selection` 内同时设 `-webkit-text-fill-color`），`pre` 在下（`pointer-events:none`）；焦点环与白底移到外层 `.blk-edit`（`:focus-within`）。

**JS**：`classify()` 逐字符分类（配对栈，O(n)）→ 逐行渲染（行号 + 族色 + 错误 + 配对底色）→ `syncBox()` 同步尺寸与滚动；`ResizeObserver` 保住 `resize:vertical`。

**性能/体积**：仅窗口内一份实例，不触碰画布 → 零跟手性风险；预估 **+5~6KB**（含行号与状态栏）。

## 八、红线（不得触碰）

1. **数据/逻辑零改动**：`#blkInput.value` 仍是唯一真源，着色/行号/状态栏纯显示层；不改保存、导出、拼接输出语义。
2. **不加配置类 UI**（无开关、无设置项、无图例进产品；错误符号表/色板皆为文件头常量）。
3. **画布拖拽/平移/缩放零影响**；画布块内联编辑行为不变（只新增放大入口）。
4. **视觉基调不变**：仍是 macOS 浅色毛玻璃（coding 化只加"编辑器骨架"，不换深色主题）。
5. **体积预算 ≤ +6KB**。
6. **零领域语义（新增红线）**：引擎不得为符号预设内容归属（不写"某某符号=台词/音效/…"），符号只按结构分族着色；新增/更换符号族一律走结构表。

### 13.2 探查要点（实施前 13 例真机探针 `_build/diag_hl_quote_zone.mjs`）

- 改动前 R0 分支在配对判定**之前**无条件命中 → **任何**引号内的 `，`/`,` 都标红；`hlStatus()` 用**独立正则**数一遍 → **两处必须同改**（只改一处会出现「颜色放过、计数仍报」的分叉）。
- 既有栈可直接复用（`“ ”` 在 `HL_PAIRS`、半角 `"` 在 `HL_TOGGLE`）→ 只需把「哪些引号算边界」独立成常量表，不必新写配对器。
- 反例已查实：JSON 式 `{"a":1, "b":2}` 的 `,` 在引号**之间**（栈内无引号）→ 不会被误豁免；半角引号奇偶错乱以最新开启者为界；跨行在换行处重置栈（与拍板②一致）。
